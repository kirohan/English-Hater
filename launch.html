Online Beta Launch Check

A founder-only readiness page. It does not expose secret keys.

Launch order

  1. Create Supabase project and run supabase-setup.sql.
  2. Paste the public Project URL + anon/publishable key into backend-config.js.
  3. Create your founder account and promote only that account to admin.
  4. Publish reviewed content with Cloud Publisher.
  5. Deploy this folder to Cloudflare Pages.
  6. Add your production URL to Supabase Auth redirect/site URLs.
  7. Test signup, email confirmation, password reset, profile photo and the two-device rule on real devices.
